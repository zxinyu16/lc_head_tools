# 单证之间：页面结构与交互设计 V1.0

## 设计范围与假设

面向外贸制单人员，按电脑浏览器优先设计。此为设计评审原型，不连接 CloudBase、不发送文件，不进行 OCR 或模型识别；当前业务与模板预设保存在浏览器本地。正式开发再接入账户、持久业务库、文件存储、识别任务和文档生成。

原型入口：同目录 index.html，建议通过本地 HTTP 服务打开。

## 设计规范

- 目的：减少重复填写，保留信息来源，并在生成前发现缺失信息。
- 风格：文档工作台 / Industrial-utilitarian；细线分区、纸张预览、克制使用强调色。
- 色彩：背景 #F4F3EE；文字 #24332F；主操作 #176B52；纸张 #FFFFFF；待核对 #A66A16。
- 字体：PingFang SC、Noto Sans SC；预览单据用 Georgia。
- 布局：220px 固定导航；核对页面左侧原文、右侧表单，比例约 40:60；预览页左侧检查、右侧纸张，比例约 32:68。
- 页面主动作保持一个；状态用文字与颜色共同表达；表单均有可见标签，键盘焦点明确。
- 电脑端并排对照；窄屏改为上下排列。手机端优先查看和补充，复杂模板排版以电脑端为主。

## 信息架构：四个一级页面

| 页面 | 主要区域 | 核心操作 | 下一步 |
|---|---|---|---|
| 业务总览 | 业务列表、待处理数、新建入口 | 新建、继续、查找、复制业务 | 制单工作台 |
| 制单工作台 | 资料录入、基础信息、额外条款三个步骤 | 上传或填写、核对、补充要求 | 预览与检查 |
| 模板中心 | 模板列表、用途、版本、预设字段 | 新建、复制、编辑、应用 | 当前业务预览 |
| 预览与检查 | 输出设置、问题清单、单据预览 | 修正、切换单据、生成、下载 | 生成记录 |

账户与工作空间设置放在用户菜单中，不增加一级导航。原型暂不包含登录界面。

## 主流程

新建业务 → 选择文件录入或手动填写 → 核对基础信息 → 编辑额外条款 → 应用模板 → 检查并预览 → 生成文件。

允许跳转步骤并保存不完整草稿；正式生成受必填与确认状态限制。上传不是必经步骤。

### 页面一：业务总览

正式版业务列表显示业务名称、客户、信用证号、更新时间、状态、经办人；提供搜索、状态筛选、继续、复制和归档。不使用过多统计图抢占制单入口。

空状态：显示「上传信用证开始」和「手动创建」两个明确入口。已有业务时，以「继续制单」为主要行动。

原型仅保留一笔演示草稿；新建或载入示例前提示替换。正式版创建独立业务，不替换旧业务。

### 页面二：制单工作台

#### 步骤 1：资料录入

上传 PDF 或图片，显示文件名、类型、大小、处理状态；允许指定「正本 / 修改证」。正式版支持拖放、多页排序、删除、重新上传。

状态链：已选择 → 上传中 → 排队 → 识别中 → 待核对；失败时显示失败原因、重试、手动填写入口。失败不丢失已填写数据。

修改证独立保留。识别完成后展示「原值 / 新值 / 来源」，逐项接受或保留；不自动覆盖已经确认的值。

手动路径：标准字段直接录入；支持自定义「关键词名称 + 值」。正式版粘贴整段文本先生成候选字段，用户确认后写入。

#### 步骤 2：基础信息

左侧显示原文件页或文字摘录，右侧显示业务名称、信用证号、交易双方及发票信息。

每个提取字段正式版具有「原文来源」入口，点击定位高亮；来源与用户修改记录分别保留。申请人、受益人、买卖方和收货人采用独立角色模型，需要确认对应关系。

基础信息修改后撤销之前的确认状态；保存不等于确认。无信用证业务允许信用证号为空。

原型采用整体确认框；正式版对低置信度、冲突字段提供逐项确认，并仅允许批量确认已查看且无冲突的字段。

#### 步骤 3：额外条款

左侧聚焦 46/47 场原文，右侧为条款编辑。

每条保存：名称、类型、内容、适用单据、是否必填、来源、确认状态；正式版增加输出位置、原文保留开关、历史记录。

三种类型：

1. 编号字段：PI、保单、合同、订单等；缺值建立待填项。
2. 固定文字：需出现在单据上的声明或指定措辞。
3. 操作要求：份数、签字、盖章等，进入检查清单。

适用范围：全部单据、特定单据多选。原型先提供全部、发票、装箱单三种选择。

正式版支持同一语义字段的关键词别名配置；不能仅凭关键词命中决定适用范围。新增条款时名称必填；同名字段出现不同值时提示冲突，禁止静默覆盖。

### 页面三：模板中心

模板分为版式模板、字段与条款预设、单据组合，界面用标签切换，避免混淆。

首版正式编辑流程：上传 Word / Excel → 识别占位符 → 映射字段 → 设置额外条款位置 → 用示例数据预览 → 保存版本。

「从当前业务保存」弹窗说明保存范围：字段结构与适用规则默认保留；编号、日期、金额与交易双方默认清空。固定公司信息或固定声明需用户明确选择保留。

应用模板：不清空当前业务值；同名字段先检查类型、范围及含义，存在差异则展示合并确认。新增字段进入待填列表。模板版本变更不影响历史生成快照。

原型可保存命名预设并应用，演示同名字段保留当前值；尚未实现真实版式上传、差异合并和版本编辑。

### 页面四：预览与检查

左侧选择模板和单据，显示待处理项；点击问题直接返回对应步骤。右侧显示抬头与额外条款预览。

检查分三类：

- 阻止正式生成：所选单据必填信息缺失、要求的编号缺失、未确认冲突、必要确认未完成、占位符未映射。
- 提醒：可能过长的地址、排版溢出、需人工判断的措辞。
- 操作清单：签字、盖章、份数等，需要在业务完成时记录执行状态。

可随时查看带「草稿」标记的预览；有阻止项时，正式生成不可用，并明确列出原因。

正式生成状态：生成中 → 成功 / 失败；失败可重试，成功记录数据与模板快照。编辑后提示原生成文件已过期，需重新生成。

原型下载的是文字演示摘要，不是 Word、Excel 或正式贸易单据。原型检查覆盖当前业务，而正式版按所选输出单据集合计算，避免无关单据阻断生成。

## 关键边界与反馈

| 场景 | 界面行为 |
|---|---|
| 文件类型或大小不支持 | 就地解释限制；保留当前草稿 |
| 识别失败或超时 | 保留文件，允许重试或转手动 |
| 条款要求编号但没有编号 | 展示必填待补项，不自动猜填 |
| 识别值与用户修改冲突 | 展示两值和来源，待用户选择 |
| 保存失败 | 明确提示未保存，保留页面内容 |
| 模板缺少字段位置 | 生成检查给出字段及模板编辑入口 |
| 长内容跨页 | 预览高亮溢出，允许换行/续页，禁止截断 |
| 删除条款/替换草稿 | 确认后执行；正式版记录可恢复历史 |
| 模板更新 | 新业务使用新版本，旧输出保留原版本 |

## 本轮可体验内容

四页面切换；文件选择与格式/大小验证；基础信息编辑与确认撤销；新增/删除条款；条款类型和范围设置；发票/装箱单预览切换；必填缺失阻止演示摘要下载；模板预设命名保存/应用；刷新后恢复本地草稿。

## 尚未接入的正式功能

真实 OCR / 模型提取、云端上传、原文件预览、修改证差异、账号权限、多笔业务列表、全文关键词解析、真实 Word/Excel 模板、版本管理及正式单据导出。

## 设计评审与开发顺序

先评审信息层级、表单字段和条款适用范围；用真实脱敏样本检验来源对照与模板位置；随后完成手动制单闭环，再接入 CloudBase 业务存储、文件处理和识别任务。
