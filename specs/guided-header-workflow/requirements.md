# 三步制单与结果对应：需求

## 用户目标

制单员先填写自己已知或愿意填写的信息，再导入信用证文本补充候选，集中核对每项信息的保留范围，最后一次生成所选单据，并能按信用证号和发票号找到输出文件。

## 验收条件

1. 新建业务时，页面先进入手填步骤；所有字段均可暂时留空，草稿能保存。
2. 第二步允许粘贴 SWIFT 信用证文本或选择 UTF-8 `.txt` 文件；文件读入后自动提取候选。PDF/图片当前仅是附件，不宣称 OCR。
3. 提取结果不能静默覆盖业务字段。用户可选择候选，并在第三步确认字段内容与适用单据；未识别的 46/47 场原文仍可查看。
4. 第三步允许每个基础字段选择“不输出/仅发票/仅装箱单/两种单据”，条款维持适用单据选择；必需字段被排除时应阻止对应单据生成。
5. 用户可选择本次生成发票、装箱单或两者。检查通过后，一个按钮生成所选 Word 抬头草稿。
6. 结果页对每个已生成文件显示单据类型、信用证号、发票号、生成时间、版本状态和打开/保存入口；修改业务后旧文件标为历史版本。

## 边界

本期只从可复制的 SWIFT 文本抓取候选，不实现 PDF/图片 OCR；CloudBase 仍暂缓。输出是可编辑抬头草稿，不是完整贸易单据合规审查。
