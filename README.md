# 信用证辅助制单微信小程序

[产品需求](PRD.md) · [页面设计](design/页面结构与交互说明.md)

## 当前可用

本项目已在微信开发者工具中导入并编译。打开本目录的 `project.config.json`，模拟器默认显示业务总览。

- 新建、搜索、复制、归档多笔本地业务。
- 手动填写交易双方、发票号和日期；修改后重新核对。
- 录入 46/47 场相关编号、固定文字或操作要求，并指定适用单据。
- 按“名称：内容”格式批量整理关键词，再逐条确认范围。
- 粘贴含 SWIFT 场次的信用证文字，提取信用证号、交易方候选和 46/47 场明确标出的 PI/保单编号；逐项核对、选定适用单据后导入。
- 保存和应用字段模板；动态编号不带入新业务，同名规则冲突时不覆盖。
- “结果”页预览发票、装箱单抬头，提示缺失项；生成后在独立的最终输出区域打开最新 Word 文件，显示生成时间、版本状态及更早文件。
- 从微信会话导入 PDF，或从相册/相机导入图片，仅供本地查看；同名同大小文件会被拦截以防重复导入。
- 业务总览页可将本机全部业务、模板和生成记录备份为 JSON 文件发送到微信会话保存，并可从备份恢复（恢复前需确认，会覆盖本机现有数据）。

## 使用限制

业务资料仅保存在当前微信小程序的本地存储；清理小程序数据前请先使用备份功能导出，否则资料会删除。导入文件也保存在本机。文字提取只支持已复制出的、带场次标记的信用证文本；图片和扫描版 PDF 尚无 OCR，其他未识别要求只展示原文。尚无云端同步、多人权限、正式发票或装箱单版式。Word 文件是抬头草稿，不含货物明细，使用前须人工核对。

开发样本可在 macOS 上用 `python3 scripts/ocr-pdf.py <PDF路径> --output <文字文件路径>` 进行本机 OCR，再把文字粘贴进小程序核对。此工具不上传文件，也尚未集成进小程序运行环境。

项目已配置用户提供的正式 AppID `wx95fc344fe5970613`。首页可选择手动填写，或导入信用证 SWIFT 文本（粘贴 / `.txt` 文件）；文本只产生待核对候选。PDF / 图片目前仅作为原件附件。真机预览需要小程序管理员或开发成员权限；已完成预览推送，尚未完成真机验收、体验版上传或发布。

## 开发和验证

安装 Node.js 后执行 `npm test` 和 `npm run check`。修改 `src/domain/documents.mjs` 后执行 `npm run sync:miniprogram`，把共用业务规则同步到小程序。当前 31 项测试覆盖条款适用范围、编号缺失、模板动态值清空、冲突阻止、业务复制、Word 包结构与 CRC、页面全流程、备份恢复、保存失败保留输入和文件导入拦截。

下一步需真实脱敏信用证和单据模板，才能设计识别字段映射与正式版式。
